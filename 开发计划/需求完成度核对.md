### 2. 完全系统访问权限 + 不乱删文件 ⚠️

| 能力 | 现状 |
| --- | --- |
| 任意命令执行 | `run_command`（L4）可以跑任意 PowerShell / 可执行文件 |
| 删除文件 | `delete_path`（L3）可删文件/目录 |
| 高危保护 | 两者**执行前必须用户确认**：聊天区确认卡片展示完整参数，60 秒未确认按拒绝处理 |
| 文件路径边界 | 文件类工具（read/write/move/list/delete）受 Tool Guard 限制在 桌面 / 文档 / 下载（含 OneDrive 同名目录）+ 本轮显式选择的附件；拒绝 `..`、UNC、device namespace、`C:\Windows`、`Program Files` |
| 审计 | 每次工具调用写 `audit_log`（工具名 / 参数 / 结果 / 风险等级 L0~L4） |

- 结论：**"像 Codex 那样执行任意系统操作"已经具备**（走 `run_command` + 确认）；但**文件类工具仍刻意收窄在白名单内**，因此对 `C:\Windows` 之类路径用 `write_file` 会被拒。
- 如果要"完全文件系统访问"，只需放开 `localmind/scripts/tool_policy.py::default_allowed_roots`（这会削弱防误删保护，属于产品取舍，需你确认后再改）。

### 3. 自动更新记忆文档 ✅ 已完成（2026-09-14 实现）

实现方式（电脑端）：

- **记忆文档**：`%APPDATA%\LocalMind\memory.md`，单文件 markdown，是跨会话记忆的唯一事实源；用户可读、可编辑，卸载时随 `%APPDATA%\LocalMind` 一起删除。首次读取时按模板创建（**已存在则不覆盖**，所以原地升级不会丢记忆）。
- **注入**：每次发消息前读取并注入为【长期记忆】system 消息（在会话摘要之前），上限 3000 字符（约 1500 token），超长自动截断并提示。
- **沉淀**：每轮结束后**复用原本就有的那次摘要模型调用**，一次返回 `{summary, facts[]}`——摘要进 `session_summaries`（服务本会话），事实去重后追加进记忆文档（服务跨会话）。**不额外增加模型调用次数**。
- **去重**：归一化比较 + 包含判断 + 长后缀判定（"用户的项目在 X"与"用户的项目位于 X"算同一条）；同一 `turn_id` 只写一次，重试不会重复。
- **整理**：文档超过 4000 字符自动让模型压缩合并成结构化小节；覆盖前留 `memory.md.bak`，整理失败保留原文。
- **界面**：设置页「记忆管理 → 记忆文档」可查看路径、直接编辑保存、一键整理、打开所在文件夹。
- **失败处理**：只写「正常完成」的轮次（停止生成/失败不写）；记忆读写失败只记日志，不影响对话主流程。
