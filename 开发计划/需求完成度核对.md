## 一、六项主需求

### 1. 双端注册/登录（同账号 → 手机授权操控电脑）✅

| 环节 | 实现位置 |
| --- | --- |
| 账号服务（注册/登录/刷新/登出、密码 Argon2id、token 只存哈希） | `relay-server/src/account.rs`、`account_db.rs` |
| 设备登记与控制配对（申请 → 目标机批准 → `tenant_id`） | `relay-server/src/account_db.rs`（`create/approve/reject_pairing_request`） |
| Windows 端账号页 + 待批准授权申请 | `localmind/src/pages/AccountPage.tsx`、`stores/accountStore.ts` |
| Android 端账号页 + 远程控制页 | `localfile/.../ui/account/`、`ui/remote/` |
| 指令与结果双向通道 | Relay WSS 转发 + `localmind/src-tauri/src/relay_wss.rs` |

- 「同账号」只解决设备归属与发现；**真正能互控必须由电脑本机点批准**（ADR-003）。
- 已验证：Relay 集成测试 `account_auth_enrollment_and_control_approval_flow`；模拟器 E2E（申请 → 批准 → 发指令 → 电脑执行 → 结果回传手机）。
- 2026-09-14 补强：access token 30 分钟过期后双端会自动刷新重试（此前不刷新，长时间开着会报错）。

### 2. 完全系统访问权限 + 不乱删文件 ⚠️

| 能力 | 现状 |
| --- | --- |
| 任意命令执行 | `run_command`（L4）可以跑任意 PowerShell / 可执行文件 |
| 删除文件 | `delete_path`（L3）可删文件/目录 |
| 高危保护 | 两者**执行前必须用户确认**：聊天区确认卡片展示完整参数，60 秒未确认按拒绝处理 |
| 文件路径边界 | 文件类工具（read/write/move/list/delete）受 Tool Guard 限制在 桌面 / 文档 / 下载（含 OneDrive 同名目录）+ 本轮显式选择的附件；拒绝 `..`、UNC、device namespace、`C:\Windows`、`Program Files` |
| 审计 | 每次工具调用写 `audit_log`（工具名 / 参数 / 结果 / 风险等级 L0~L4） |

- 结论：**"像 Codex 那样执行任意系统操作"已经具备**（走 `run_command` + 确认）；但**文件类工具仍刻意收窄在白名单内**，因此对 `C:\Windows` 之类路径用 `write_file` 会被拒。
- 如果要"完全文件系统访问"，只需放开 `localmind/scripts/tool_policy.py::default_allowed_roots`（这会削弱防误删保护，属于产品取舍，需你确认后再改）。

### 3. 自动更新记忆文档 ❌ 未完成（本次核对确认）

现状：

- ✅ 每轮对话结束会自动生成**会话摘要**并写入 `session_summaries`，下一轮作为上下文注入（`localmind/src/hooks/useStreamChat.ts::generateSummary`）。
- ✅ 设置页「记忆管理」可查看/搜索/删除 会话摘要 与 长期记忆。
- ❌ `memory_entries`（长期记忆）**从来没有数据写入方**：`save_memory` IPC 已实现（`chat_api.rs` → `storage/mod.rs`），但前端没有任何调用点。

要做的最小实现（建议）：

1. 每轮结束后追加一次轻量抽取调用：把「本轮用户偏好/长期事实/结论」按 `category + content` 写入 `memory_entries`（复用现成的 `save_memory`）。
2. 记忆管理界面补「手动新增/编辑」（现在只能删除）。
3. 如需"记忆文档"形态，可在 `%APPDATA%\LocalMind\memory.md` 同步落一份可读副本（卸载清理逻辑已覆盖该目录）。

### 4. 提升 Agent 能力 / Harness ✅（一轮完成，持续优化）

- Harness v2 已是默认路径：结构化工具错误回灌、单轮预算（`request_limit=8`、`tool_calls_limit=12`）、单工具超时、输出截断、Turn 级 Trace。
- 同模型 A/B：baseline `18/24` → Harness v2 `24/24`，见 `开发计划/Phase1-Harness评测报告.md`。
- 2026-09-14 修复：会话摘要喂错输入（喂的是用户消息而非助手回复）、fallback 永不触发、审计风险等级恒为 L2。

### 5. 移除内置 API Key，改用户自填 ✅（并已加密）

- 安装包与仓库内**不含任何真实 key**（已对 `LocalMind.exe` / `LocalMindSetup.exe` / `LocalFile.apk` 做 `sk-<20+字符>` 扫描，均为 0 命中）。
- Windows：`%APPDATA%\LocalMind\auth.json`，值为 AES-256-GCM 密文（`ENC:` 前缀，密钥由 device_id 派生）。
- Android：EncryptedSharedPreferences（Android Keystore 保护）。
- 环境变量 `LOCALMIND_DEEPSEEK_KEY` 仅作开发调试兜底，优先级低于前端传入的 key。
