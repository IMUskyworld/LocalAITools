## 四、交付范围与关键结论速览

### 4.1 系统形态
- **LocalMind（Windows exe）**：Tauri 2.x + React/TS + Rust，在线（经网关调 Deepseek-V4-Pro）/离线（llama.cpp 本地推理）双模，桌面助手指令执行（白名单+二次确认）
- **LocalFile（Android apk）**：Kotlin + Jetpack Compose，文件 AI 处理（摘要/翻译/重命名）+ 在线/离线双模对话 + 对话式远程控制电脑
- **RelayCloud（云端）**：单台 2C4G 云主机 Docker Compose 编排 relay-server（Rust+axum WSS 中继）+ new-api（网关：key 隐藏/模型映射/令牌额度）

### 4.2 双端功能模块与交互控件（用户核心诉求）
- **LocalMind 4 页面**（P-W1 主对话/P-W2 模型管理/P-W3 远程控制面板/P-W4 设置）：逐页面交互控件清单（按钮/输入框/列表/开关/进度条/确认弹窗）见《高层架构设计》§6.4 与《UserStory》§5
- **LocalFile 5 页面**（P-A1 首页三 Tab/P-A2 文件处理/P-A3 对话/P-A4 远程控制/P-A5 模型设置）：同样到控件级别，含低端机降级引导与危险操作本机二次确认，见《高层架构设计》§6.5 与《UserStory》§5

### 4.3 关键量化指标（全部经 G3 冻结）
- 远程指令端到端时延 P95 ≤ 3s；配对建立 ≤ 60s
- 离线推理吞吐：PC ≥ 5 tok/s（16GB 无独显）/ Android ≥ 8 tok/s（骁龙 8 系旗舰）
- 安装包：exe ≤ 80MB / apk ≤ 60MB；冷启动 ≤ 3s
- 云端月成本 ≤ 150 元（≤ 50 用户小范围分发）

### 4.4 MVP 范围（W1~W10）
F1~F11（全 P0）+ F12（网关配置与令牌管控，P1）+ D-1（双端打包交付）：双端在线/离线对话、模型一键下载（断点续传+校验）、Android 文件处理、网关 key 隐藏与令牌管控、对话式远程控制（配对+白名单+结果回传）、exe/apk 打包交付。完整版（W11~W16）：F13~F14（多档模型推荐、P2P 通道与截图回传）。
