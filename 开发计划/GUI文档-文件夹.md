# 4. Windows 端 — LocalMind

### 4.1 总体布局

LocalMind 采用**三栏式桌面助手布局**，支持常驻任务栏托盘、热键唤起、迷你浮窗和完整窗口四种形态。

#### 4.1.1 完整窗口布局

```
+------------------------------------------------------------------+
| [菜单] LocalMind - Deepseek-V4-Pro                    [— □ ×]     |
+-----------+--------------------------------+---------------------+
|           |                                |                     |
| 会话列表  |      主对话区域                 |   快捷工具面板       |
|           |                                |                     |
| [搜索...] |  ┌──────────────────────────┐  |  ┌───────────────┐  |
|           |  │ AI: 回复内容 (Markdown)   │  |  │ 翻译          │  |
| [+ 新会话] |  └──────────────────────────┘  |  │ 总结          │  |
|           |                                |  │ 润色          │  |
| 会话 1    |  ┌──────────────────────────┐  |  │ 代码助手      │  |
| 会话 2    |  │ 用户: 输入的消息           │  |  │ 思维导图      │  |
| 会话 3    |  └──────────────────────────┘  |  │ 联网搜索 [off]│  |
|           |                                |  └───────────────┘  |
|           |  ┌──────────────────────────┐  |                     |
|           |  │ [输入框________________] │  |                     |
|           |  │ 附件              ▶ 发送 │  |                     |
|           |  │ 在线 | Deepseek-V4-Pro   │  |                     |
|           |  └──────────────────────────┘  |                     |
+-----------+--------------------------------+---------------------+
| [状态栏]  已连接 | Token: 1,234/8,192 | 远程设备: 0 台在线     |
+------------------------------------------------------------------+
```

#### 4.1.2 迷你浮窗布局

+------------------------------------------+

#### 4.2.6 设置模块

**位置**: 独立设置窗口。

| 标签页 | 控件清单 | 功能描述 |
|--------|---------|---------|
| **通用** | 开机自启 Toggle、语言切换 ComboBox（中/英）、主题切换 ComboBox（亮/暗/跟随系统）、字体大小滑块 | 基础偏好设置 |
| **AI** | 在线模型名（只读，Deepseek-V4-Pro）、离线上下文长度下拉 (2048/4096/8192)、Temperature 滑块 (0-2)、Top-P 滑块、离线模型管理入口 | AI 参数配置；MVP 单一模型档位，不提供模型选择 |
| **快捷键** | 快捷键列表 + 重新绑定按钮 + 冲突检测提示 + 恢复默认按钮 | 自定义全局快捷键 |

| **数据** | 导出所有会话按钮、清除历史按钮（二次确认）、数据存储路径选择、占用空间显示 | 数据管理 |
| **远程控制** | 远程控制开关 Toggle、配对码生成按钮、已授权设备列表（含撤销按钮） | 远程控制授权管理 |

#### 4.2.7 远程控制接收模块

当收到手机端远程控制指令时，经白名单校验 + 危险动作本机二次确认后执行。

| 触发条件 | UI 响应 | 控件 |
|---------|--------|------|
| 收到配对请求 | 弹出授权确认窗口 | Dialog：显示手机设备名称 + "允许" / "拒绝" 按钮 |
| 配对成功 | 状态栏更新 | 状态栏显示 "远程连接: 1 台设备" |
| 收到远程指令（白名单内安全动作） | 自动在当前活跃会话中执行 | 消息列表显示 "[远程] 帮我总结文档..." |
| 收到远程指令（危险动作，如文件写入/删除） | 本机弹窗二次确认 | Dialog：指令内容大字 + "允许执行" / "拒绝" + **15 秒倒计时默认拒绝** |
| 指令执行完成 | 结果自动回传手机端 | 五态状态机：executing → done / failed（含原因） |
| 连接断开 | 状态栏更新 + 托盘通知 | 状态栏恢复 "远程设备: 0 台在线" |

## 5. Android 端 — LocalFile

### 5.1 总体布局

LocalFile 采用**底部导航栏 + 四页签**结构：文件、对话、远程、我的。

```
+-----------------------------------------------+
|  LocalFile                    [模式] [设置]|
+-----------------------------------------------+
|                                               |
|          [ 主内容区域 --- 随页签切换 ]            |
|                                               |
|  ┌───────────────────────────────────────────┐ |
|  │                                           │ |
|  │  文件列表 / 对话消息 / 远程面板 / 设置页    │ |
|  │                                           │ |
|  └───────────────────────────────────────────┘ |
|                                               |
+-----------------------------------------------+
|  文件      对话      远程      我的             |
+-----------------------------------------------+
```

## 7. GUI 设计规范

### 7.1 设计语言总览

| 维度 | Windows (LocalMind) | Android (LocalFile) |

### 7.3 Android 端色板策略

使用 Material Design 3 动态配色方案，通过 `MaterialTheme.colorScheme` 驱动。关键色值映射：

| Token | 说明 |
|-------|------|
| `primary` | 主题色，用于 FAB、重要按钮、活跃指示 |
| `onPrimary` | 主题色上的文字颜色 |
| `primaryContainer` | 主题色容器，用于选中态背景 |
| `surface` | 页面背景 |
| `surfaceVariant` | 卡片 / 对话框背景 |
| `outline` | 边框和分割线 |
| `error` | 错误状态 |

确保亮/暗模式下对比度通过 WCAG AA 标准（正文 >= 4.5:1，大文字 >= 3:1）。

### 7.4 通用 UI 原则

1. **空状态 (Empty State)**: 所有列表/页面在无数据时显示插画 + 说明文字 + 引导按钮，而非空白。
2. **加载状态 (Loading)**: 优先使用骨架屏 (Skeleton Screen)，避免全屏转圈。列表分页加载时底部显示加载指示器。
3. **错误状态 (Error)**: 网络错误 / 服务器错误时显示具体原因 + 重试按钮，而非通用 "出错了"。
4. **确认操作**: 不可逆操作（删除、清空历史）必须有二次确认弹窗。
5. **无障碍 (a11y)**: 支持屏幕阅读器 (Windows Narrator / Android TalkBack)；所有图标按钮提供 contentDescription；对比度满足 WCAG AA。
6. **触控友好**: Windows 端可交互区域 >= 32x32 px，Android 端 >= 48x48 dp。
7. **键盘导航**: Windows 端支持 Tab 键焦点切换 + 常用快捷键提示。

## 8. 技术栈速查（对齐架构冻结决策）

| 端 | 框架 | 语言 | 推理引擎 | 打包 |
| :--- | :--- | :--- | :--- | :--- |
