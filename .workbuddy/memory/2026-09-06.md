## 免编译重打包：注入 DeepSeek key（已完成）

**背景**：换机后 LocalMind 对话无反应。根因是 exe 内烘焙的旧 key 失效。

**关键机制（重要）**：`localmind/src-tauri/src/agent_process.rs:79` 的 `deepseek_api_key()`
优先读**运行时环境变量** `LOCALMIND_DEEPSEEK_KEY`，为空才回退 `option_env!` 编译期烘焙值。
→ **改 key 无需重新编译 Rust**，只要安装时写入用户环境变量即可，省掉 llama-cpp-sys 的 20-30 分钟编译。

**本机（新设备）无构建环境**：无 Rust/cargo、MSVC 工具集、cmake、libclang、pnpm、NSIS、node_modules、target 缓存；无 E 盘。
→ 完整链路打包不可行，改走「免编译重打包」路线。

**免编译重打包流程（可复用）**：
1. **取文件**：旧的 `LocalMindSetup.exe` 支持 `/S` 静默自安装 → 从 `%LOCALAPPDATA%\LocalMind`
   取出 localmind.exe、scripts\make_doc.exe、scripts\localmind-agent\（含 _internal，1639 文件）。
   **不需要 7-Zip 解包**（本机也没有）。
2. **拿 NSIS**：本机无 winget/choco。SourceForge 下载失败（仅 1 字节）；github.com 网页被墙（HTTP 000），
   但 **api.github.com 与 objects.githubusercontent.com 通**。
   → 从 `tauri-apps/binary-releases` 的 `nsis-3.11` release 用 API 下载 asset（id 317051073，2.36MB zip），
   Python `zipfile` 直接解压到 `C:\Users\world\AppData\Local\tauri\nsis-3.11\`
   （正好匹配 build-installer.ps1 第 5 行默认路径）。zip 内顶层已含 `nsis-3.11/`，故解压到 `tauri\` 父目录。
3. **踩坑**：installer.nsi 加了中文注释后 makensis 报 `Bad text encoding`
   → NSIS `Unicode true` 要求脚本为 **UTF-8 with BOM**，用 Python 以 `utf-8-sig` 重写即可。
4. **注入**：installer.nsi 用 `!define DEEPSEEK_KEY` + 三重保险
   ① `WriteRegExpandStr HKCU Environment`（永久）
   ② `SendMessage HWND_BROADCAST/WM_WININICHANGE`（免注销刷新）
   ③ `System::Call kernel32::SetEnvironmentVariable`（完成页「立即运行」继承）
   Uninstall 段同步 `DeleteRegValue`。布局保持 agent 在 `scripts\localmind-agent\`（命中 find_agent_exe 的 scripts/ 候选）。
5. **验证**：直接 spawn `localmind-agent.exe` 并注入环境变量，POST `/agent/stream`
   → 事件序列 thinking→done，AI 正常回复。**端到端 PASS**。

**其他结论**：
- key 有效；`deepseek-chat` 模型名仍可用（HTTP 200），无需改 agent_server.py。
- `reg.exe` 被本机安全策略拉黑，PowerShell 工具在本环境**不回显 stdout**（连 "hello" 都不返回），
  两者都不能用于验证；改用 spawn 子进程做端到端验证更可靠。
- .gitignore 已忽略 `LocalMindSetupBuild/`、`LocalMindScripts/`、`*.exe`（但 `!LocalMindSetup.exe` 例外，
  即新包会被 git 追踪——**内含明文 key，push 公开仓库前须作废该 key**）。
