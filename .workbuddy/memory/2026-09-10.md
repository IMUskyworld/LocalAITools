### 核心发现（全部有代码行号取证）

**P0**：
1. **跨轮记忆断裂**（`useStreamChat.ts:92` 只存最终 content，tool_calls/results 全丢）
   → 这是"Agent 性能差"的头号成因，换模型也治不好
2. **数据纯内存**（`storage/mod.rs:11` 注释自述"MVP 使用内存存储，正式版切换至 SQLite"）
   → 重启全丢；Memory 零基础设施
3. **`run_command` 注册且无防护**（`main.rs:78`，`tools.rs:158` 直跑 PowerShell）
4. **`delete_path` 注册且无防护**（`main.rs:76`，`tools.rs:129` remove_dir_all）
5. **文件操作无路径边界**（全部 `PathBuf::from(path)` 直用）
6. **Context 无窗口管理**（`useStreamChat.ts:69` 全量取历史）
7. **工具定义三处重复**：Python 7 个 / `tools.ts` 3 个（死代码）/ `tools.rs` 12 个

**P1（关键）**：
- llama.cpp 推理引擎**完全孤立**（Windows+Android 双端都是死代码）。
  Windows 端 `model::start_inference` 只改一个 bool，从不碰引擎；
  Android 端 `LlamaBridge` 自述 "stub implementation"
- 大量 mock：`chat::send_message` 回显 mock；`model/mod.rs` 4 个函数空壳 `Ok(true)`；
  `check_device` 硬编码 "Intel Core i7-12700H"；`storage::save_config` 空壳
- `AppConfig::load()` 硬编码 `wss://relay.example.com/ws`（RelayCloud 残留假域名）
- `get_app_info` 每次 `Uuid::new_v4()` → device_id 不稳定，双端无法配对
- `shared-contract/` 与 `wssClient.ts` **100% 死代码**，零 import
  → **双端互联是 0 基础设施，所谓"复用旧契约"实际要从零写**
- 手机端 API key 编进 APK（`DeepSeekConfig.kt:11`）

### 关键判断（回答"Agent 性能差怪谁"）
| 归因 | 占比 | 依据 |
|---|---|---|
| Harness/Runtime | ~60% | 跨轮记忆断裂 + Context 无管理 + 工具能力面被冻死 |
| Model | ~25% | 7B 确实弱，但已有 `parse_tool_call_from_text` 文本兜底缓解 |
| Architecture | ~15% | 三套工具定义、两套会话 API、无持久化 |

**特别讽刺的一点**：`tools.ts:3-4` 注释写着"精简为 3 个核心工具，因为 7B 模型工具多了不稳定"
——但**在线模式用的是 DeepSeek**，完全不需要为 7B 让路，**在线模式也被自我阉割**。

### 给用户的实施路线（Phase 0-5）
- **Phase 0 止血**：移除 5 个高危死命令 + StorageManager 换 SQLite + device_id 持久化
- **Phase 1 修记忆**：`tool_calls` 表落盘 + 拼回上下文 + Context 窗口管理
  ← **这是性能主战场，修完很可能不换模型就明显改善**
- **Phase 2 立权限**：Tool Registry 中心化 + Permission Gateway + 回收站 + audit_log
  + `run_command` 重新引入（默认关闭+逐条确认）。原则"先修锁，再开锁"
- **Phase 3 Memory**：三层模型（Working/Session/Long-term）+ 7 步生命周期
  + **建议不要自动往 Markdown 追加**（无法去重/检索/过期，必然成垃圾堆）
  → 权威存储用 SQLite，Markdown 只做只读视图
- **Phase 4 双端**：Tailscale(tsnet) 优先 + 局域网降级；Command/Event 含 seq/幂等/confirm_required
- **Phase 5 清理**：删 llama.cpp、shared-contract、wssClient、mock
